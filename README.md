# TALA Study Planner

دفتر دراسة ومهام شخصي بواجهة عربية RTL وهوية بنفسجية وذهبية.

الموقع: https://aboodsharef-maker.github.io/models-3d/

المستودع نفسه محفوظ باسم models-3d. لم يتم إنشاء مستودع أو إعداد Pages جديد.

## ما يقدمه التطبيق

- مواد قابلة للإضافة والتعديل والحذف والترتيب، مع ألوان وأيقونات مخصصة.
- أقسام متداخلة حتى ثمانية مستويات، ومهام مباشرة أو داخل الأقسام.
- تعديل المهام ونقلها وترتيبها، إكمالها وإلغاء الإكمال، ونسب إنجاز تراكمية للأقسام والمواد.
- جدول أيام وتقويم، ومواعيد امتحانات بعد تنازلي.
- دفتر ملاحظات وملاحظات مهام غنية التنسيق باستخدام Tiptap: الخطوط والأحجام والألوان والتظليل والقوائم وعلامات الصح واتجاه الكتابة.
- إنجازات محسوبة من البيانات الفعلية، وثلاث لوحات ألوان وخطوط عربية محلية.
- تصدير واستيراد JSON مع فحص البنية والروابط والتواريخ والتنسيقات، وتنزيل نسخة من الدفتر الحالي قبل استبداله.

تُجهز ست مواد أولية بأسماء قابلة للتعديل، دون مهام أو امتحانات أو إنجازات وهمية.

## البيانات والخصوصية

الحفظ التلقائي في IndexedDB تحت اسم tala-study-planner. لا توجد قاعدة بيانات خلفية أو حسابات أو مزامنة بين الأجهزة، ولا تُحفظ البيانات في GitHub Pages.

استخدمي نفس المتصفح للعودة إلى الدفتر. مسح بيانات الموقع أو انتهاء جلسة تصفح خاص قد يفقد البيانات؛ صدّري نسخة JSON بانتظام، واستورديها لنقلها إلى جهاز آخر. يوضح التطبيق حالة الحفظ ويعرض خطأً قابلًا لإعادة المحاولة إذا تعذّر التخزين. لا يعمل دفتر متزامن على أكثر من تبويب؛ تُعرض رسالة عند اكتشاف تعديلات في تبويب آخر.

بنية البيانات تحمل schemaVersion ومعرّفات UUID وdeviceId وrevision وطوابع إنشاء وتحديث، لتسهيل الترحيل وإضافة المزامنة مستقبلًا. المزامنة نفسها غير منفذة حاليًا.

## التطوير والتحقق

```sh
npm ci
npm test
npm run build
npm run dev
```

افتحي /models-3d/ من عنوان التطوير. يستخدم التنقل hashes حتى تعمل الروابط وإعادة التحميل على GitHub Pages. يتطلب البناء Node.js 24 كما في workflow.

التنفيذ: src/data.ts للحسابات وفحص النسخ، src/storage.ts للحفظ الذري وتسلسل الكتابات، src/components/ للمكونات والمحرر والنوافذ، src/pages/ للشاشات، public/assets/ للهوية المستقلة الشفافة. الخطوط من حزم Fontsource محفوظة ضمن البناء، ولا يعتمد التطبيق على CDN أو خطوط عن بعد.

## النشر

نفس ملف .github/workflows/pages.yml ونفس بيئة github-pages. عند الدفع إلى main: npm ci ثم npm test ثم npm run build، ورفع dist/ فقط. لا تُرفع ملفات الاختبارات أو المستندات المحلية أو ملفات المجسمات القديمة أو البيانات الشخصية إلى الموقع.

## نقطة رجوع المشروع السابق

وسم Git مشروح ومرفوع: backup/models-3d-before-tala-2026-10-31.

للفحص دون تعديل main:

```sh
git switch -c inspect-old-gallery backup/models-3d-before-tala-2026-10-31
```

لا تعيدي نشر الوسم بنفس workflow الجديد مباشرة؛ نسخة الوسم تحمل ملفات المعرض وطريقة نشره الأصلية كاملة. لاستعادة الموقع القديم راجعي تغييرات main أولًا ثم أنشئي عملية استعادة واضحة من الوسم، مع إبقاء أي تعديلات لاحقة محفوظة.

## الهوية والمراجع

استُخدمت الصور المرفقة كمرجع للون والمزاج البصري فقط. واجهة التطبيق مكونات فعلية، وليست صورة. الشعار والتاج والفراشة والوردة والهلال والنجوم ملفات SVG مستقلة بخلفيات شفافة؛ الخطوط Tajawal وCairo وAmiri من Fontsource وفق تراخيص الحزم.

## تطبيق أندرويد والتحديثات (1.1)

افتحي الرابط في Chrome على أندرويد واضغطي «تثبيت التطبيق». إذا لم تظهر النافذة، استخدمي قائمة Chrome ثم «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية ← تثبيت». هذا تطبيق ويب قابل للتثبيت PWA، وليس إصدار متجر Play أو APK. يفتح بأيقونته في نافذة مستقلة؛ الآيفون يستمر كموقع عادي ويمكن إضافته للشاشة الرئيسية.

تُخزن ملفات الواجهة والخطوط والمصحف للعمل دون اتصال بعد اكتمال التهيئة الأولى. كلمة «جاهز دون اتصال» داخل التطبيق تعني أن خدمة العمل دون اتصال أصبحت جاهزة. يلزم الإنترنت للتنزيل الأول ولتلقي الإصدارات الجديدة. لا يُرفع دفتر المستخدمة أو سجل العبادة إلى أي خدمة.

كل npm run build يولد sw.js وversion.json مع بصمة للمحتوى. النسخة الجديدة تنتظر، ويظهر زر «تحديث الآن» عند جاهزيتها. التحديث لا يحذف IndexedDB، ويُمنع تطبيقه أثناء الحفظ أو فتح نافذة تعديل. يتم البحث عن تحديث عند فتح التطبيق/العودة إليه وعند الاتصال وكل 15 دقيقة أثناء فتحه. التحديثات تصل بعد دفع التغييرات إلى main ونجاح نشر GitHub Pages؛ لا حاجة لإعادة تثبيت التطبيق في كل مرة.

tools/generate-icons.mjs يولد PNG بمقاسات 180 و192 و512 وأيقونة maskable من SVG مستقل. ملفات PNG ملتزم بها في المستودع.

## الصلاة والقرآن

سجل يومي قابل للتعديل للصلوات الخمس، وخطط ختمة متعددة بمدة وعدد صفحات قابلين للتخصيص، وسجل ورد يومي من/إلى صفحة مع ملاحظة. تحسب الختمة الصفحات المختلفة فقط؛ إعادة قراءتها لا ترفع نسبة الختمة مرتين. توجد قراءة داخل التطبيق بترقيم 604 صفحة ونص عثماني، مع اختيار سورة وصفحة وحجم خط وإضافة الصفحة إلى الورد. لا توجد مواقيت أذان أو تنبيهات أو طلبات موقع.

النص العربي محفوظ دون تعديل من Al Quran Cloud / Islamic Network، إصدار quran-uthmani. المصدر والحقوق والروابط وبصمة الاستجابة الأصلية موضحة في public/quran/SOURCE.txt وبيانات JSON. جرى فحص وجود 114 سورة و6236 آية و604 صفحة. لا يُجلب النص من خدمة خارجية أثناء استخدام التطبيق؛ هو ملف ثابت ضمن الإصدار.

أصبح إصدار مستند البيانات 2، مع ترقية تلقائية لدفاتر الإصدار 1 ونسخه الاحتياطية دون حذف موادها أو ملاحظاتها. نسخة IndexedDB نفسها ما زالت 1 لأن مخزن البيانات لم يتغير. يشمل تصدير JSON بيانات الصلاة والختمة والورد أيضًا.

يمكن سحب الصفحة للأسفل من أعلاها ثم الإفلات عند ظهور «اتركي للتحديث». تفحص الحركة إصدار التطبيق وتطبقه إن كان جاهزًا، وإلا تعيد فتح الصفحة المحفوظة. لا تعمل الحركة أثناء الحفظ أو داخل نوافذ التعديل والمحرر؛ السحب الأفقي والقصير لا يفعّلانها.
