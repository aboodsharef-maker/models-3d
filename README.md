# مجسّمات 3D

معرض عربي ثابت لعرض المجسمات ثلاثية الأبعاد، يبدأ بالقفص الأبيض. يعمل على استضافة ملفات ثابتة دون خادم خلفي أو قاعدة بيانات.

## الملفات

- `index.html`: واجهة المعرض.
- `models.js`: قائمة المجسمات وأسماؤها وروابطها ومقاساتها.
- `models/white-cage.glb`: القفص بوحدات المتر، مع حركة `DoorOpen` لفتح الباب.
- `models/cage.html`: العارض البديل الذي لا يحتاج WebGL.
- `vendor/`: مكتبة model-viewer مثبتة محليًا مع ترخيصها ورقم إصدارها.
- `scripts/build_cage.py`: إعادة توليد القفص عند تعديل أبعاده أو شكله.
- `.github/workflows/pages.yml`: نشر تلقائي عند الدفع إلى main.

## التشغيل والتحديث

للتجربة المحلية شغّل `python -m http.server 8765` من مجلد المشروع ثم افتح `http://localhost:8765`. افتح المشروع عبر HTTP أو HTTPS، لأن عارض GLB يستخدم JavaScript modules.

لإضافة مجسم: ضع ملف GLB في models، وأضف سجلًا إلى models.js مع id فريد واسم ووصف وأبعاد ومواصفات. إذا تضمن الملف حركة، اكتب اسمها في animation. إذا كان المجسم يحتاج أدوات خاصة، يمكن توفير صفحة مستقلة في fallback. لا تضف أمثلة وهمية إلى المعرض العام.

صيغة GLB المفضلة هنا هي glTF 2.0 ذات الأصول المضمنة، دون Draco أو KTX2 أو ملفات خارجية، كي لا يحتاج المتصفح خدمات أو مفككات ضغط خارج المشروع. وحدات glTF هي الأمتار. تجنب ملفات ضخمة على الهاتف. المجسمات المضافة إلى المستودع العام قابلة للتنزيل من الجمهور.

كل مجسم له رابط قابل للمشاركة باستخدام `#id`. الموقع لا يستقبل طلبات رسم ولا ينشئ مجسمات بنفسه. تطلب التصميم في محادثة Codex المتصلة بهذا المستودع، ثم تُضاف ملفات المجسم ويُدفع التحديث إلى main. لا يوجد اتصال تلقائي دائم بين المحادثة والموقع.

للنقل إلى أي استضافة ثابتة أخرى: ارفع ملفات المشروع كما هي؛ لا يوجد build command. لم تُضبط استضافة خارج GitHub لأن المستخدم لم يحدد اسم المزوّد الآخر بعد.

## أصل التصميم

القفص 150 × 110 × 120 سم؛ بوكس 3 × 3 سم؛ فتحة باب صافية 80 × 114 سم؛ ضلفة 79 × 113 سم؛ شبك وجوانب بيضاء وسقف عشب أخضر وأرضية مفتوحة. السقف يدخل ضمن ارتفاع 120 سم في GLB. فتحات الشبك والملمس توضيحيان، وليس الملف مخطط تصنيع معتمدًا.

## المكتبة

يستخدم العارض مكتبة Google model-viewer بصيغتها المجمعة المحلية، بترخيص Apache 2.0 كما في vendor. الوثائق: https://modelviewer.dev/docs/
